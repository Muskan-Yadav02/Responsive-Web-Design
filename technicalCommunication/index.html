Getting Started

Web development begins with three core technologies: HTML, CSS, and JavaScript.

HTML defines the structure of a page, CSS controls its appearance, and JavaScript adds behavior.

A simple HTML document can begin with the following declaration:

<!DOCTYPE html>
  • Choose a code editor.
  • Create a project folder.
  • Add an HTML file.

Keeping your files organized makes larger projects easier to maintain.

HTML Foundations

HTML uses elements to describe the meaning and structure of content.

Most elements have an opening tag and a closing tag.

<h1>Welcome to my website</h1>

Headings should describe the hierarchy of information on a page.

Semantic elements such as <main> and <nav> make documents easier to understand.

  • Use headings in logical order.
  • Give images useful alternative text.
  • Use semantic HTML whenever possible.
CSS Layout

CSS controls how HTML elements are displayed and positioned.

Modern layouts commonly use Flexbox and Grid.

. container { display: flex; }

Flexbox is particularly useful when arranging elements along one dimension.

Grid is useful when you need control over both rows and columns.

.layout { display: grid; grid-template-columns: 1fr 2fr; }
  • Start with a simple layout.
  • Use responsive units when appropriate.
  • Test layouts at different screen widths.
JavaScript Basics

JavaScript allows a webpage to respond to user interaction.

Variables can store values that your program needs to use later.

const message = "Hello, developer!";

Functions group reusable pieces of logic together.

Events allow JavaScript to react when users click, type, or interact with elements

button.addEventListener("click", handleClick)
  • Use meaningful variable names.
  • Keep functions focused on one task.
  • Prefer modern JavaScript syntax.
Debugging and Testing

Debugging is the process of finding and fixing problems in your code.

Browser developer tools provide useful information about HTML, CSS, and JavaScript errors.

console.log("Checking the current value");

Testing small pieces of functionality can prevent bugs from spreading through an application.

When something fails, reproduce the problem before attempting to fix it.

if (value === expected) { console.log("Test passed"); }
  • Read error messages carefully.
  • Check the browser console.
  • Test changes one step at a time.
